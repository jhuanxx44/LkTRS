这次演示能说明什么？
真实运行的部分
Groth16 证明、授权验签、同一期关联、持久钱包计数、重复计数追责、成员撤销，以及独立进程验签。耗时为本机实测，包含对应 API 的开销。
如何理解追责
重复计数槽且挑战不同才触发本演示的追责；不必等到第四次。证明有效不代表业务可接收。追责解析到注册用户，不提取私钥，也不识别所用设备。
明确的研究边界
传感器读数和身份登记是模拟的；setup 为本地单方生成。同一期跨账号、跨环可关联，已有匿名性反例。此演示不构成完整安全证明或生产部署。所有角色由同一本地进程编排，独立验签另启进程。
